# Research Canvas 0.2.0

首个可通过开源仓库分发的版本：本地 Web 画布、Codex 插件和 VS Code 扩展共同支持从研究想法到代码文件的设计流程。

## 本版内容

- 手动建立三层画布：整体模块、内部功能、代码文件。功能与文件可多对多关联。
- 为节点定义多个输入输出，用自然语言描述连线条件、分支、循环及跨层端口绑定；外层输入可分发到多个内部功能。
- 在画布中选中模块，交给 Codex 插件读取设计；画布也能通过本机 Codex App Server 发起调研、方案和实现任务。图是设计记录，不是执行引擎。
- 使用 VS Code 扩展打开画布、定位已存在的关联文件，或复制模块上下文。
- 提供 MIT 许可、源码包、可移植 Codex 插件 ZIP、VSIX、文件清单和 SHA-256 校验和。

## 安装

安装步骤见 [本地分发与发布验收](release.md)。Codex 插件和画布运行需要 Node.js 20.12 或更新版本；从源码构建发布包需要 Node.js 22 或更新版本。

## 已验证范围

已完成 Windows 环境下的核心测试、浏览器操作、Codex 插件隔离安装与五个 MCP 工具调用、VSIX 隔离安装、编译包解压运行、源码包干净重建，以及调研→方案→代码生成流程验收。生成代码通过五项独立测试。测试夹具用于验证产品流程；研究结果仍需使用者核验。其他操作系统尚未完成完整安装验收。

实现任务会在调用模型前检查工作区的沙箱写入权限；检查失败时会提示选择通过写入检查的工作区。
